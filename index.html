Digital hardware · Verification automation

Automated Hardware Verification

A Verilog, Tcl and Perl pipeline that compiles a threshold-filter design, checks its behavior and generates an HTML report.

Earlier workflow recording. Current source and verification runs include the expanded 14-check suite.

What I built
A self-checking simulation, automation driver and report parser that return a failing status for failed or incomplete verification.
Verification
14 cycle-level checks cover threshold boundaries, sustained inputs, synchronous reset and noise. Regression tests also confirm that deliberately incorrect RTL fails.
Scope
Digital simulation of an 8-bit threshold filter; physical optical-sensor performance and FPGA deployment have not been measured.

Optical inspection · Synthetic-data prototype

Opti-DefectNet

A PyTorch CNN and OpenCV data generator for exploring clean-versus-defective optical-fiber imagery.

Approach
Seeded synthetic images and independent 70/15/15 train, validation and test splits.
Verification
Dataset fingerprints, split-integrity checks, and held-out precision, recall and confusion-matrix reporting.
Scope
Real microscope images and manufacturing acceptance criteria remain unvalidated.

Computer vision · Known-parameter simulation

PyOptics

An interactive OpenCV demonstrator comparing an original frame, simulated lens distortion, and correction of the same distorted frame.

Approach
Forward Brown-Conrady distortion and cached rectification maps for barrel and pincushion models.
Verification
Camera-free regression checks require at least 80% lower reconstruction error on a synthetic grid’s central crop.
Scope
A known-parameter demonstration; physical-camera calibration and frame-rate benchmarks are future work.
